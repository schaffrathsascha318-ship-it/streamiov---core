# Pulse Defender

Status: **Development — not released**

## Spielziel
Verteidige den Energiekern. Bewege dein Schiff horizontal und schieße die herabkommenden Drohnen ab. Jede übersehene Drohne kostet einen Schildpunkt. Die Wellen werden schneller.

## Steuerung
- Tastatur: Pfeiltasten oder A/D bewegen, Leertaste schießen
- Maus/Touch: Schiff horizontal bewegen; Schuss erfolgt automatisch

## Lokal starten
`index.html` in einem aktuellen Browser öffnen. Keine externen Abhängigkeiten.
