# Neon Relay

Status: **Development — not released**

## Spielziel
Sammle in einer Runde so viele Energie-Orbs wie möglich und weiche roten Störfeldern aus. Eine Runde dauert 60 Sekunden. Eine Kollision kostet ein Leben; die Runde endet bei null Leben oder nach Ablauf der Zeit.

## Steuerung
- Tastatur: Pfeiltasten links/rechts oder A/D
- Maus, Touchpad oder Touchscreen: Spieler horizontal ziehen
- Start und Neustart über die Schaltfläche im Spiel

## Lokal starten
index.html direkt in einem aktuellen Browser öffnen. Das Spiel hat keine externen Abhängigkeiten und benötigt keinen Server.

## Vor einer Veröffentlichung zu prüfen
- [ ] Runde startet und endet zuverlässig
- [ ] Tastatursteuerung funktioniert
- [ ] Maus-/Touchsteuerung funktioniert
- [ ] Kollisionen und Punktestand sind korrekt
- [ ] Neustart setzt den Spielzustand vollständig zurück
- [ ] Layout funktioniert auf Desktop und Mobilgeräten
- [ ] Längere Spielrunde ohne Fehler
- [ ] Testergebnis mit Gerät, Browser und Datum dokumentiert

CI oder ein erfolgreicher HTML-Check ist kein Ersatz für diese echte Spielprüfung.
