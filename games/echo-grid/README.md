# Echo Grid

Status: **Development — not released**

## Spielziel
Merke dir die aufleuchtende Folge auf dem 3×3-Feld und wiederhole sie in derselben Reihenfolge. Jede Runde fügt ein Feld hinzu. Ein Fehler beendet den Lauf.

## Steuerung
- Maus oder Touch: Feld antippen
- Tastatur: Tasten 1 bis 9, entsprechend der Position von links oben nach rechts unten

## Lokal starten
`index.html` in einem aktuellen Browser öffnen. Keine externen Abhängigkeiten.
