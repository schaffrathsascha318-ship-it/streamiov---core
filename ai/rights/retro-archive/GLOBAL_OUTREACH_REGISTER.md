# Streamiov Global Game Rights Outreach Register

**Purpose:** collect responses from rights holders about whether they are open to a conversation. This register is not a game-development backlog.

## Hard rules
- No game, remake, remaster, port, sequel, prototype, ROM, ISO, source archive, artwork, music, or other game asset is to be built, acquired, copied, or used as part of this outreach phase.
- A dormant, delisted, discontinued, commercially inactive, or abandoned title is not thereby public domain or available for derivative works.
- Record only verifiable rights-holder identity, official contact route, date, source URL, exact response, and follow-up status.
- Do not send messages automatically. Prepare drafts only; a human must decide whether to send.
- Do not make commitments, promise revenue, imply permission, or accept terms.
- An enquiry or positive reply is not a licence. Only a signed written permission/licence from the competent rights holder can move a title to a rights-cleared state.
- Rejections are marked DECLINED and removed from the active-interest queue. No repeated contact after an explicit refusal unless the rights holder invites it.
- If a contact route is for merchandise only, do not use it to request game-development rights; ask for the correct department or mark route unsuitable.

## Response statuses
| Status | Meaning |
|---|---|
| DISCOVERED | Candidate identified; ownership not yet established |
| RIGHTS_HOLDER_UNVERIFIED | Possible owner/successor identified; evidence incomplete |
| CONTACT_ROUTE_VERIFIED | Official contact route confirmed |
| DRAFT_PREPARED | Non-binding enquiry drafted, not sent |
| SENT_BY_HUMAN | Human has sent the enquiry |
| NO_RESPONSE | No reply yet; follow-up date recorded |
| REVIEWING | Rights holder says it is reviewing the enquiry |
| INTERESTED | Rights holder invites discussion; no permission implied |
| DECLINED | Rights holder explicitly declines; remove from active queue |
| ROUTED | Referred to another rights holder or department |
| TERMS_DISCUSSION | Preliminary discussion of possible terms |
| WRITTEN_PERMISSION_PENDING | Written permission/licence not yet executed |
| RIGHTS_CLEARED | Signed written permission verified for the specific title, components, activities, territories, platforms, term, and other scope |
| BLOCKED | Ownership/contact/terms unresolved or rights holder prohibits the intended use |

## Outreach message scope
Ask only whether the organisation is open to an initial conversation and which department/rights holder handles the relevant game software IP. State that Streamiov is not assuming rights are available. Do not pitch or promise a build, release, funding, revenue split, exclusivity, platform, territory, or launch date before the owner invites discussion and scope is known.
