# Reports

Luna should create one report per completed task, for example `TASK-114-audio-engine.md`.

Include:

- Task file and task ID
- Working branch and final commit SHA
- Changed files
- Summary of implementation
- Exact commands run
- Tests: PASS / FAIL / NOT RUN, with concise output
- Hardware/platform actually tested
- Known limitations and follow-up work
- Pull request URL, if created

Never paste credentials, environment files, tokens, or session data.
